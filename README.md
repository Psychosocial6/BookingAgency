# BookingAgency

---

A pet project aimed at learning Spring and modern backend development technologies.

BookingAgency is a RESTful backend application that simulates a hotel booking service. It allows users to browse hotels across various countries and book rooms for selected dates.

# Tech Stack

---

* Java 21
* Spring Boot 4.1.1
* Spring Web MVC
* Spring Data JPA
* Apache Maven
* Lombok

# Project Status

---

The project was recently started and is currently under active development. More detailed documentation and API specifications will be added as the project evolves.
